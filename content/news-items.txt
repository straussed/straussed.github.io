# News items for news.html — this file is the source of truth for the gallery.
#
# TO ADD AN ITEM
#   1. Put the full-size photo in images/large_image_originals/news/
#      (any size straight off the camera; it gets resized for you)
#   2. Add a block below, in any order — the page is sorted by date for you.
#   3. Run:  ./tools/build-images.sh && ./tools/build-news.py
#
# FORMAT
#   One block per item, blank line between blocks. Three fields:
#
#     image:   filename as it sits in images/large_image_originals/news/.
#              Repeat this line to put several photos under one caption; they
#              stack at full width and count as a single item on the page.
#     date:    ISO, either 2026-07-18 or 2026-07 if the day does not matter.
#              Displayed as "July 2026"; the day is only used for ordering.
#              Free text like "Summer 2026" will not work — it cannot be sorted.
#     caption: one sentence, shown after an em dash
#
#   The caption is also used as the image's alt text, so it is worth writing one
#   that says what is in the photo rather than only what the news is — compare
#   "Our NSF grant was funded" with "The field team celebrating the new NSF
#   grant at camp", which works as both a caption and a description.
#
#   A caption can contain a link, written as [text](https://example.com).
#   External links open in a new tab. The alt text keeps only the link text, so
#   a screen reader is not read a URL.
#
#   Lines starting with # are ignored. A long value can wrap onto the next line
#   as long as the continuation is indented. Commas, quotes and & are all fine;
#   they get escaped for you.
#
# EXAMPLE — uncomment and edit, or copy the shape for your own items:
#
# image: 2026-07-fieldwork.jpg
# date: 2026-07-18
# caption: The team returns to Talek for the summer field season.
